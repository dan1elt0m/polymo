# jsonplaceholder-demo

Databricks Asset Bundle generated by polymo for the `posts` stream.

- `databricks.yml` — bundle + pipeline resource (`main.raw`)
- `src/jsonplaceholder_demo/client.py` — generated fetch/schema code, no polymo import at runtime
- `pipelines/posts.py` — pipeline source, `@dp.table` over `jsonplaceholder_demo.client`

## Deploy

    databricks bundle deploy -t dev
    databricks bundle run -t dev jsonplaceholder_demo_pipeline

Table lands at `main.raw.posts`. Use `-t prod` for production.
